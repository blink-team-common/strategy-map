# 戦略マップ

戦略を「左下の複数スタート → 集約 → 右上のゴール」で描くツール。
`index.html` 1枚だけで動く（サーバー・ビルド・依存ライブラリなし）。マップは JSON ファイルとして手元に保存する。

## 使い方

`index.html` をブラウザで開くだけ（ダブルクリックでも、`file://` でも、どこかに静的ホスティングしても動く）。

| 操作 | やり方 |
|---|---|
| ノードを足す | 「＋ ノード」またはキャンバスをダブルクリック |
| 矢印でつなぐ | 「→ 接続」→ 元のノード → 先のノード |
| 編集 | ノードをクリック → 右のパネルでタイトル・担当・期限・完了日・種別・メモ |
| 並べ直す | 「▤ 自動整列」（左下→右上・集約の形に配置） |
| 開く | 「📂 開く」で手元の JSON を読み込む |
| 保存 | 「💾 保存」または Ctrl/⌘+S（Chrome/Edge では同じファイルに上書き、それ以外はダウンロード） |
| 書出し | 「⇩ 書出し」で JSON をダウンロード |
| 下位マップへ | ノードの「リンク先マップ」にファイル名を書くと、ダブルクリックで潜れる（初回だけマップの入ったフォルダを選ぶ。「← 戻る」で上位へ） |
| 範囲選択・削除 | 左ドラッグで範囲選択 → Delete |
| 視点移動・拡大 | 右ドラッグで移動、右上の －／＋ で拡大縮小 |

編集中の内容はブラウザ（localStorage）にも残るので、閉じて開き直しても続きから始まる。

### ノードの種別

| 種別 | 色 | 意味 |
|---|---|---|
| スタート | 緑 | 左下の起点（複数可） |
| タスク | 青 | 途中の状態 |
| 節目 | 紫 | マイルストーン |
| ゴール | 金 | 右上の終点 |

完了日を入れると緑のリングと ✓ が付く。担当 👤 と期限 📅 は丸の右上に出る（期限切れは赤字）。

## マップの JSON

```jsonc
{
  "title": "マップ名",
  "titleBlock": { "title": "盤面右下の表題", "name": "担当名", "date": "2026-12-20" },
  "nodes": [
    { "id": "n1", "label": "ここから\n始める", "kind": "start", "assignee": "田中", "due": "2026-08-31" },
    { "id": "n2", "label": "ゴールに\n到達している", "kind": "goal", "link": "sub-map.json" }
  ],
  "edges": [ { "from": "n1", "to": "n2" } ]
}
```

項目の詳細と書き方のルール（ラベルは「〜している」の状態で書く、循環させない、など）は [CLAUDE.md](./CLAUDE.md) にまとめてある。AI にマップを書かせるときもこれを渡せばよい。

## 補足

- 画面には社内の共有版（ログイン・共有保存・Jira 連携）向けの機能も入っているが、サーバーが無い環境では自動的に隠れてローカル版として動く。ノード編集の「Jira キー」欄は、ローカル版では入力しても表示には使われない。
- 共有版のサーバー側（Cloudflare Workers）は [internal-tools](https://github.com/blink-team-common/internal-tools) の `strategy-map/` にある。
